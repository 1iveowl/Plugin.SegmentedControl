# Claude Code guidance

Follow [AGENTS.md](AGENTS.md) for this repository's instructions. It is the canonical
guidance for every assistant; keep this file as a pointer so the rules do not drift.

The rule that is easiest to break by habit: never add yourself as a co-author, never
put a "generated with" or 🤖 line in a commit message or pull request, and never
appear in this repository's git history or contributor list. See
[AGENTS.md](AGENTS.md#attribution-an-agent-is-never-an-author).
